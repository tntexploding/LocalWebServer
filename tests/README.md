# 独立验证工程

`tests/` 只通过发布入口、配置文件和公开 HTTP/WS/WebUI 接口观察系统，不导入 `apps/server/src` 中的内部执行类，也不要求生产代码识别测试环境。

- `e2e/` 启动已编译的服务器子进程，使用临时项目目录和操作系统分配的端口。
- `browser/` 使用 Playwright 驱动生产构建后的 WebUI。
- `container/` 验证容器配置初始化逻辑；完整镜像烟雾测试由 `npm run test:container` 独立
  构建临时镜像、网络和接收端，并通过公开动作 API 验证受控的容器间 HTTP 访问；同时静态
  验证 GHCR 工作流的权限隔离、目标平台、供应链证明和外部 Action 固定方式。
- `support/` 仅保存测试进程、临时配置和端口管理工具。

测试数据全部位于系统临时目录，并在用例结束后清理。正式配置、模板、令牌和运行日志不会被读取或修改。
